# Privacy Policy: Job Leads Agent

Last updated: 11 November 2026

Job Leads Agent is a personal tool used only by its developer. It is not available to other users.

**What it accesses (with the developer's own permission):**
- Gmail (read-only): only job-alert emails in one label, to extract job titles, companies and links.
- Google Drive (only files the app itself creates): a Google Sheet of job leads and a folder of cover letter drafts.

**How data is used:** Job posting text and the developer's resume are sent to the Anthropic Claude API to score roles and draft cover letters. No data is sold, shared with advertisers, or used for any other purpose.

**Storage:** Results are stored in the developer's own Google account and private GitHub repository. Credentials are stored as encrypted GitHub Secrets.

**Removal:** Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact: via the support email shown on the Google sign-in screen.
